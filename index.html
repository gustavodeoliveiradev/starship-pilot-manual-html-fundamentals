1. Pre-Flight Protocol

Ensure all safety locks are disengaged and life support systems are stable before engine ignition.

Initial Check Script

Run the diagnostic script in the central flight computer:

$ sysctl --check life_support
[OK] Oxygen levels: 98%
[OK] Gravity matrix: 1.0G
[OK] Shield generators: ONLINE

2. Hyperdrive Sequence

Calculating coordinates and spooling up the warp core requires precise timing to avoid spatial distortion.

  1. Lock target coordinates via Navigation Console.
  2. Charge Techyon Coils: execute command warp --charge 100%
  3. Engage Safety Buffer and initiate jump.

3. Emergency Override

In case of total power loss or localized containment breach, bypass primary relays immediately.

# WARNING: Executing override will clear current nav logs
# Enter manual override key:
$ sudo systemctl restart warp_containment.service --force
