# 🚀 Starship Pilot Manual — Class IX Interceptor

Um guia de referência rápida desenvolvido para praticar **navegação interna** e **exibição de código** em HTML5 puro, sem estilização CSS.

O projeto simula um painel/manual de navegação espacial com atalhos de rolagem para seções internas e comandos de terminal pré-formatados.

---

## 🚀 Tecnologias e Conceitos Aplicados

Neste projeto, explorei as seguintes tags e estruturas do HTML5:

* **Navegação Interna (Âncoras):** `<nav>` com links `href="#id"` conectados aos atributos `id` dos artigos.
* **Módulos Independentes:** `<article>` para delimitar cada seção do manual.
* **Formatação de Código e Terminal:** `<pre>` e `<code>` para exibir linhas de comando e scripts mantendo a formatação original.
* **Retorno ao Topo:** Link `href="#"` no `<footer>` para navegação em ciclo.
* **Listas e Tabelas:** `<ol>` para etapas sequenciais e `<table>` para frequências de rádio.
